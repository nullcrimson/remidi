# Glossary

Never translated: drum names, family names, engine and product names, "MIDI", "Drumverter", note names (`C1`, `D#2`), file extensions.

Tone: short, plain, in the words the language's common apps use for the same action, so a user is never surprised. Address: Sie (de), vous (fr), вы (ru, lowercase); tú (es), você (pt), tu (it); polite forms in ja and ko; the pronoun omitted where possible in zh; bare imperatives and impersonal forms in pl.

Each language's terms and tone: `locales/<code>/GLOSSARY.md`.
