| English | Japanese |

| drum (a kit piece, cymbals included) | パーツ (counted N個のパーツ) |
| note | ノート (note number: ノート番号) |
| note map | ノートマップ |
| note layout of an engine | ノート配置 |
| preset | プリセット |
| convert | 変換 / 変換する |
| remap | リマップ |
| mapping (the drum → note assignment) | マッピング, 割り当て |
| source / target engine | 変換元 / 変換先のドラム音源 |
| FROM / TO | 変換元 / 変換先 |
| channel | チャンネル (ドラムチャンネル, チャンネル10, 全チャンネル) |
| octave | オクターブ (オクターブ表記 for the C-1 / C-2 setting) |
| drag and drop / drop a file | ドラッグ＆ドロップ / .midファイルをドロップ |
| pick a file | ファイルを選択 |
| on-screen piano | 鍵盤 |
| exact | 一致 |

| unrecognized | 不明 |

| reset | リセット |
| reload | 再読み込み |
| export / import | エクスポート / インポート |
| favourites | お気に入り |
| filter (placeholder / label) | 検索… / 絞り込み |
| chip (saved preset on the main screen) | ボタン |
| GitHub issue | GitHubのIssue |

Tone: です/ます in sentences and tooltips (「…してください」「…できます」). Buttons, tabs, column headings and chips are plain nouns or noun+を+verb stems, as in Windows, macOS and Japanese DAWs: 変換, 保存, キャンセル, 閉じる, 名前を変更, ノートを編集. Short hints under options are plain form (最も近いパーツで鳴らす). Errors follow the OS pattern 「…を読み込めませんでした」. Counts use 個 for drums and notes, 件 for edits and changes, ファイル directly after the number (3ファイル); filter chips read 全12件 / 変更3件. Status chips put the label before the number with a space (近似 3).

Punctuation: 、。 in sentences, full-width ：（）「」 around Japanese text, no spaces between Japanese and Latin words or numbers (ドラムMIDI, チャンネル10), 〜 for numeric ranges in sentences. Brand-typical long-vowel spellings: コンバーター, エディター, ブラウザ (as in Chrome/Google).

English kept: engine, product and drum names (China, Crash, Tom 4…), MIDI, Drumverter, DAW, GitHub, FAQ (common on Japanese sites), MID badge, note names C-1/C-2, file extensions, Enter / Ctrl+Enter key names. Drummer jargon uses the standard katakana forms Japanese drummers use: ゴーストノート, リムショット, プリセット, リマップ.
