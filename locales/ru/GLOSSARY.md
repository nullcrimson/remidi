| drum (a kit piece, cymbals included) | инструмент |

Forms: address with lowercase «вы», imperatives in the polite plural in prose and prompts («Добавьте файл .mid», «Выберите…», «Нажмите…»), infinitives on buttons and menu items as Windows, macOS and Russian DAWs do («Скачать», «Сбросить всё», «Переименовать», «Конвертировать и скачать»), «Отмена» for cancel. Failures start with «Не удалось…». Counts in chips and tags use «слово: N» («заменено: 3», «изменено: 2») so no plural agreement is needed; full sentences use one / few / many selects, with *[other] (fractions) taking the genitive singular. Status words (exact / approximated / dropped / unrecognized) are neuter short forms everywhere: tags, report groups, map tables.

Short hint text under an option describes what the option does, third person, like the tooltip: «звучат на ближайшем инструменте», «убираются из файла».

Brand and engine names stay undeclined and untranslated. Where a case ending would be needed, an apposition carries it: «плагин EZdrummer», «сервис Drumverter», «в плагине { $target }»; after prepositions that need no ending on a foreign name («в EZdrummer», «из GetGood Drums») the bare name is used.

English kept, because that is what Russian drummers and producers say or see: ghost notes, rimshot, hi-hat, crash, China, Tom (all drum names), MIDI, .mid, DAW, FAQ (nav label; the page heading is «Частые вопросы»), issue (GitHub's own UI is English-only), cookie. «Пресет» and «плагин» are the established Russian transliterations.
