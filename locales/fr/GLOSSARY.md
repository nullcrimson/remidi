## Tone and forms

- Address with « vous » throughout. Instructions and hints use the imperative (« Ajoutez un fichier .mid », « Déposez… », « Choisissez… »); buttons, menu items and actions use the infinitive, as in Windows, macOS and Google apps (« Télécharger », « Annuler », « Réinitialiser », « Enregistrer », « Renommer »).
- Errors follow the French system phrasing: « Impossible de charger… », « Une erreur s’est produite », « Vérifiez votre connexion et réessayez ».
- Short hint text under an option describes the result, not a command: « remplacés par l’élément le plus proche », « supprimés du fichier ».
- Register: friendly and plain, one musician to another. Errors say what happened in plain words (« Le convertisseur ne peut pas lire ce fichier : il ne ressemble pas à un fichier MIDI »); prefer verbs to abstract nouns (« Les notes du fichier, elles, ne changent pas » rather than « Simple affichage »); no officialese (« irrécupérable », « conventions d’octave » → « C-1 ou C-2 »).
- Agreement: counts of notes are feminine (« 3 notes converties », « 3 remplacées »); counts of kit pieces are masculine (« 3 éléments modifiés »). Every count that makes a word agree has a one/other select; 0 and 1 take the singular.
- French typography: narrow no-break space (U+202F) before ; : ! ? and inside « ». Typographic apostrophe ’.
- Engine and brand names are never inflected or elided: « depuis { $engine } », « vers { $engine } », « Note { $engine } », « notes { $source } » instead of « de/d’ + name ».

## English words kept

- ghost notes, rimshot, hi-hat, crash, China, tom: what French drummers actually say; drum names are never translated anyway.
- preset: standard in French DAWs and plugins (Ableton Live, most drum plugins); « préréglage » reads as a calque here.
- plugin: what French producers call EZdrummer, Superior Drummer, etc. (« un plugin de batterie »); « instrument virtuel » is formal and long, « moteur » is a calque.
- mapping, mapper, remapper: the everyday French studio word for a note layout (« le mapping GM », « remapper un MIDI »); « carte des notes » would be a calque.
- groove: common in French for a drum pattern.
- DAW, MIDI, General MIDI, Auto, FAQ, Contact, Note, SOURCE, MID: identical in French.
