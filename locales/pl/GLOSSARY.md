# Polish glossary

| English | Polish |
|---|---|
| MIDI file | plik MIDI |
| drum engine (EZdrummer, Superior Drummer…) | wtyczka perkusyjna (feminine: źródłowa / docelowa, obie wtyczki) — never "silnik" |
| drum (a kit piece, cymbals included) | instrument |
| note map | mapa nut |
| preset | preset |
| convert | konwertuj |
| remap | przemapuj |
| source / target engine | wtyczka źródłowa / docelowa |
| FROM / TO | ŹRÓDŁO / CEL |
| channel | kanał |
| octave | oktawa |
| drag & drop a file | przeciągnij i upuść / upuść plik tutaj |
| pick a file | wybierz plik |
| the on-screen piano | pianino |

Forms: bare imperatives and impersonal forms ("Dodaj pliki", "Wybierz wtyczkę", "Nie udało się…"), the way Windows/macOS/Google apps address a Polish user — never "Ty" or "Pan" spelled out, and never a formal "Państwo/Pani/Pan". Brand and engine names stay undeclined and untranslated; write "aplikacja Drumverter" or rephrase where a case ending would otherwise be needed on "Drumverter" itself.

Short hint text under an option (e.g. under "Najbliższy" / "Pomiń") describes what the option *does*, third person, not a command to the user: "gra na najbliższym instrumencie", "pomija je" — matches the longer tooltip copy ("Najbliższy gra go…") rather than switching to an imperative like "zagraj"/"pomiń" there.

Drummer/producer terms stay in English where that's what Polish drummers actually say: ghost notes, rimshot, crash, China, hi-hat, tom, MIDI, .mid, DAW. "Preset"/"presety" stays too. A single kit piece (including cymbals) in a list or column heading is "instrument" (not "bęben", which is only one drum among many, or the wordier "element zestawu") — used consistently across the UI, the guide and the FAQ.
