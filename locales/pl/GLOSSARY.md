# Polish glossary

| English | Polish |
|---|---|
| MIDI file | plik MIDI |
| drum engine (EZdrummer, Superior Drummer…) | wtyczka perkusyjna (feminine: źródłowa / docelowa, obie wtyczki) — never "silnik" |
| drum (a kit piece, cymbals included) | instrument |
| note map | mapa nut |
| preset | preset |
| convert | konwertuj |
| remap | przemapuj |
| source / target engine | wtyczka źródłowa / docelowa |
| FROM / TO | ŹRÓDŁO / CEL |
| channel | kanał |
| octave | oktawa |
| drag & drop a file | przeciągnij i upuść / upuść plik tutaj |
| pick a file | wybierz plik |
| the on-screen piano | pianino |
| missing drums (setting) | Brakujące instrumenty |
| Nearest / Drop (missing-drums options) | Zastąp / Usuń (verbs) — never "Najbliższy" / "Pomiń" |
| approximated / dropped (report, tags, tables) | zastąpione / usunięte (tables: zastąpiony / usunięty); never "przybliżone" / "pominięte" |
| closest drum | najbardziej podobny instrument (short hints: "podobnym instrumentem") |
| clean (conversion with no losses) | bez strat; never "czysto" |
| edit / override (a changed note) | zmiana; never "nadpisanie" |
| chip (saved preset on the main screen) | przycisk; never "chip" |
| tip (Stripe) / tip group label | "Postaw mi kawę"; group label "Wesprzyj projekt"; never "napiwek" (reads like a restaurant) |
| Convert more (after a conversion) | Nowa konwersja (keeps "Konwertuj" from being a prefix of another button) |
| skipped (preset edits, unsupported files) | pominięto (only for skipping; dropped drums are "usunięte") |

Forms: bare imperatives and impersonal forms ("Dodaj pliki", "Wybierz wtyczkę", "Nie udało się…"), the way Windows/macOS/Google apps address a Polish user — never "Ty" or "Pan" spelled out, and never a formal "Państwo/Pani/Pan". Brand and engine names stay undeclined and untranslated; write "aplikacja Drumverter" or rephrase where a case ending would otherwise be needed on "Drumverter" itself.

Short hint text under an option (e.g. under "Zastąp" / "Usuń") says what happens to the drums, not a command to the user: "zastępowane podobnym instrumentem", "usuwane z pliku" — matching the longer tooltip copy ("Zastąp wstawia zamiast niego…").

Limits are said like a person ("Więcej presetów się nie zmieści: maksymalnie 20"), never "osiągnięto limit". Errors say what happened in plain words ("Konwerter nie może odczytać tego pliku — to chyba nie jest MIDI"). Connection problems say "Sprawdź połączenie z internetem".

Drummer/producer terms stay in English where that's what Polish drummers actually say: ghost notes, rimshot, crash, China, hi-hat, tom, MIDI, .mid, DAW. "Preset"/"presety" stays too. A single kit piece (including cymbals) in a list or column heading is "instrument" (not "bęben", which is only one drum among many, or the wordier "element zestawu") — used consistently across the UI, the guide and the FAQ.
